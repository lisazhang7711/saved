收藏整理器
存进去容易，理出来难 —— 这一步我来

把你收藏过的东西排成一条能走完的路

粘贴 5–10 个链接（B站 / 知乎 / 微信 / 微信读书都行），它在你的浏览器里做三件事：

1

去重

同一个视频收藏两次、同一个系列的两集（P1 / P2、上 / 下），合并成一条，并列出被合并掉了哪些。

2

补缺口

没有入门就先补入门，没有实操就补实操。缺哪一步直接点名，并给出该去搜什么词。

3

排优先级

按认知顺序排，不是按收藏时间——先建立地图，再搭骨架，再动手，最后看别人踩过的坑。

链接不上传、不联网，整段解析就在你自己的浏览器里完成。

支持的形式：纯链接、标题 + 链接、标题换行链接、整段带其它文字的复制内容（会自动把 URL 抠出来）。 B站的 b23.tv 短链识别得出来但展开不了（浏览器跨域限制），会单独标出来让你补。

你这次想达成什么（决定时间怎么分）

它是怎么判的（规则全公开，你可以自己推翻）
环节规则
去重先按站内 ID 完全一致合并（B站 BV 号、知乎回答 ID、专栏 ID）； 再按标题近似合并——去掉标点空格和「（一）」「P1」「上」这类序号后， 一方包含另一方、或字符重合度超过 0.72，判为同一系列的不同集，保留一条并在下面列出被合并的。
角色五个角色靠标题关键词命中，命中词会写在每条下面。一个词都没命中就标「待定」，你自己选。
定向：入门/零基础/是什么/简介/概览/科普/速成
体系：教程/全套/完整/系列/课程/从零到/系统
实操：实战/项目/案例/手把手/跟着做/刷题/练
深化：原理/底层/深入/进阶/源码/推导/数学
避坑：坑/误区/避雷/常见错误/踩坑/复盘/血泪
排序按认知顺序「定向 → 体系 → 实操 → 深化 → 避坑」，不是按收藏时间、也不是按热度。 选了「尽快做出东西」，实操会提到体系前面；选了「搞懂原理」，深化提前。
时长粗估：B站带「合集/全套/系列/课程」按 240 分钟算，单集 25 分钟；知乎回答 8 分钟；微信文章 6 分钟；书 120 分钟。 每条都能改，改完总数跟着变。
收藏整理器是纯静态单页，解析、去重、排序全部在本地完成，不联网、不上传、不存任何账号信息，也没有追踪脚本。
上一次粘贴的内容会存在浏览器 localStorage 里，方便你回来接着改——换设备就没了。
